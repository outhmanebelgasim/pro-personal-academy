## HOW TO RUN IT (STEP BY STEP)

### 1. Prerequisites

Make sure you have installed:

- **Node.js 18+** - Download from [nodejs.org](https://nodejs.org)
- **npm** - Comes with Node.js
- **Git** - For version control


### 2. Clone the Repository

```shellscript
git clone https://github.com/outhmanebelgasim/pro-personal-academy.git
cd pro-personal-academy
```

### 3. Install Dependencies

```shellscript
npm install
```

This downloads all required packages (Next.js, React, Tailwind CSS, FontAwesome, etc.)

### 4. Run Development Server

```shellscript
npm run dev
```

### 5. Open in Browser

Navigate to: **[http://localhost:3000](http://localhost:3000)**

You'll see the website running locally with hot-reload (changes update automatically without restarting).

### 6. Build for Production

```shellscript
npm run build
npm start
```
